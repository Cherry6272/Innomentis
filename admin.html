🌐 Central Live Database Configuration

Currently running on LocalStorage Engine (Browser Sync). For a production deployment with multiple live customers across India, connect your free Supabase cloud database so all orders land in a central dashboard.

Quick 2-Minute Supabase Setup:
  1. Create a free account at supabase.com and create a new project named innomentis-store.
  2. Copy your Project URL and anon API Key from Settings › API.
  3. Add them to js/store-db.js (lines 10-15) or set window.SUPABASE_URL in your site.
  4. All orders from any phone or computer across India will automatically sync to your central Admin dashboard!
